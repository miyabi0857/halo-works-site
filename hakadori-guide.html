はかどりの使い方

導入から日々の使い方、チームでの共有、バックアップまで。 パソコンの操作に不慣れな方でも進められるよう、順を追って説明します。

導入する

  1. Python を入れる

    はかどりを動かすには Python 3.10 以降が必要です。すでに入っている場合はこの手順を飛ばしてください。

    python.org のダウンロードページ から最新版を入れます。インストール画面の最初に出る「Add Python to PATH」に必ずチェックを入れてください。 ここを入れ忘れると、あとの手順でコマンドが見つからないと言われます。

  2. ファイルを置く

    ダウンロードした hakadori-1.0.zip を右クリックして「すべて展開」を選び、 好きな場所に置きます。デスクトップでもドキュメントでも構いません。

    チームで使う場合は、この段階で共有フォルダに置いてください。（詳しくは チームで使う）

  3. 必要な部品を入れる

    展開してできた hakadori フォルダを開き、 アドレスバーに cmd と打ち込んで Enter を押します。黒い画面が開くので、 次の1行を貼り付けて Enter を押してください。

    pip install -r requirements.txt

    文字がたくさん流れて止まれば完了です。この作業は最初の1回だけです。

起動する

フォルダの中にある 「はかどり起動.bat」をダブルクリックしてください。 黒い画面が出たあと、自動的にブラウザが開きます。

初回は「ユーザーを選択してください」と表示されます。サンプルとして3人分の名前が入っているので、 「新規ユーザー作成」からご自身の名前を登録してお使いください。

黒い画面は閉じないでください。これがはかどり本体です。 閉じると画面が動かなくなります。終わるときは、はかどりの画面右上にある 「システム終了」ボタンを押してください。

最初はサンプルのタスクが数件入っています。使い方を確かめたら、削除してご自身の仕事を登録してください。

タスクを登録する

画面右上の 「＋新規タスク」 から登録します。 名前と期日だけ入れれば登録できます。あとから足せるので、最初から全部埋める必要はありません。

いちばん大事なのは「業務負荷」の選択です

はかどりは、タスクを次の3種類に分けて集計します。ここを正しく選んでおくと、 あとから「何に時間を取られていたのか」が見えるようになります。

種類こんな仕事
長期プロジェクト数週間〜数ヶ月かけて進めるもの。企画、制作、導入など
定例毎週・毎月くり返し発生するもの。月次処理、定例会議の準備など
突発急に飛び込んでくるもの。問い合わせ対応、トラブル対応など

「今週はほとんど突発だった」と数字で見えると、 来週どこを空けておくべきかが判断できるようになります。これがはかどりを作った理由です。

色の意味

一覧の行の色は、期日までの余裕を表しています。 白は余裕あり、黄色は近い、オレンジ・赤は今日か過ぎている、という見方です。 いちいち日付を読まなくても、色だけで急ぎのものが分かります。

4つの見方を切り替える

画面上部のタブで切り替えます。同じタスクを違う角度から見ているだけなので、 どれかで編集すれば全部に反映されます。

表示向いている場面
リスト全体をざっと確認する。期日順に並べ替えて優先順位をつける
カンバン作業中の状況を見る。ドラッグで「処理中」「完了」に動かせる
ガントチャート期間の重なりを見る。いつが混んでいるかが分かる
優先度マップ重要度と期日から、手をつける順番を考える

左側のメニューにある 「統計ダッシュボード」 では、 全体の進み具合、メンバーごとの持ち件数、業務分類ごとの内訳をグラフで確認できます。

チームで使う

フォルダごと共有フォルダに置くだけです。サーバーの用意もアカウント登録も要りません。

  1. 共有フォルダに置く

    社内のファイルサーバーなど、メンバー全員がアクセスできる場所に hakadori フォルダを置きます。

  2. 各自が起動する

    使う人それぞれが「はかどり起動.bat」をダブルクリックし、 「新規ユーザー作成」で自分の名前を登録します。

  3. 担当者を割り当てる

    タスクには主担当と副担当を設定できます。一覧の担当者フィルタで 「自分のタスクだけ」に絞り込めます。

同時に大人数で使うことは想定していません。 データを1つのファイルで持つ仕組みのため、数人程度までを目安にしてください。 また、ログイン認証の仕組みがありません。 共有フォルダにアクセスできる人は誰でも全タスクを見られます。 インターネットに公開することは絶対にしないでください。

バックアップと引っ越し

データは task_manager.db というファイル1つに入っています。 このファイルをコピーするだけでバックアップになります。 別のパソコンに移すときも、このファイルを持っていけばそのまま続きから使えます。

コピーするときは、はかどりを終了してから行ってください。 動いている最中にコピーすると、書きかけの状態が混ざることがあります。

添付ファイルを使っている場合は、添付の保存フォルダもあわせてコピーしてください。

困ったとき

「pip は認識されていません」と出る

Python のインストール時に「Add Python to PATH」のチェックが入っていなかった可能性が高いです。 Python を入れ直し、最初の画面でチェックを入れてください。

ブラウザが自動で開かない

黒い画面に表示されているアドレス（http://127.0.0.1: で始まるもの）を、 ブラウザのアドレス欄にコピーして開いてください。

画面がぎゅうぎゅうで見づらい

はかどりは横幅を広く使う設計です。1400px以上のディスプレイを推奨しています。 ノートパソコンで狭く感じる場合は、ブラウザの表示倍率を Ctrl と「－」 で小さくすると収まります。

タスクが1件も表示されない

画面上部の担当者フィルタが自分に設定されている可能性があります。 「担当者で絞り込み」に戻すと全件表示されます。

それでも解決しない

はかどりの画面左下にある「ご意見箱に投稿」から、不具合の報告やご要望を送れます （この内容も外部には送信されず、手元に保存されます）。 直接ご連絡いただく場合はお問い合わせページからどうぞ。 個人で開発・配布しているため、すべてにお応えできるとは限りませんが、必ず目を通します。

まだダウンロードしていない方へ

機能制限はありません。無料でお使いいただけます。
